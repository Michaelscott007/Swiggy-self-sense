# ShelfSense

Independent product exploration for Swiggy Instamart.

## Product thesis
A forecast is not a procurement decision.

ShelfSense converts uncertain demand into an explainable reorder recommendation using forecast uncertainty, inventory, inbound stock, lead time, service level, perishability, promotion uplift and local demand shocks.

## Design direction
This revision follows a more editorial, playful, premium visual language: soft color blocking, oversized typography, large rounded surfaces, minimal chrome and responsive interaction.
